# 🛒 E-Commerce Platform

A modern, full-stack e-commerce platform designed to provide a smooth, secure, and user-friendly online shopping experience.

The system is built with **React** on the frontend, **Django** on the backend, and **PostgreSQL** for database management. It provides customers with an intuitive shopping interface while giving administrators tools to manage products, users, orders, and other e-commerce operations.

---

## ✨ Features

### 👤 Customer Features

* User registration and authentication
* Secure login and logout
* User profile management
* Browse available products
* Search and filter products
* View detailed product information
* Add products to shopping cart
* Update product quantities
* Remove products from cart
* View cart total
* Place orders
* View order history
* Responsive design for desktop, tablet, and mobile devices

### 🛍️ Product Management

* Product creation and management
* Product categories
* Product images
* Product descriptions
* Product pricing
* Product stock management
* Product availability tracking
* Product search and filtering

### 📦 Order Management

* Create customer orders
* Track order details
* Calculate order totals
* Manage order status
* View customer order history

### 👨‍💼 Admin Features

* Admin authentication
* Product management
* Category management
* User management
* Order management
* Inventory management
* Dashboard and system overview

### 🔒 Security

* JWT-based authentication
* Protected API endpoints
* Role-based access control
* Secure password handling
* Environment variable configuration
* Django security features
